### Discussion Questions

I need your help to finalize these decisions for advanced search:

**1. Search Algorithm & Relevance:**
- How should search results be ranked? (Relevance score, popularity, recency, sales count, rating, seller reputation)
- Should we use full-text search (PostgreSQL full-text search) or a search engine (Algolia, Elasticsearch)?
- How to handle typos and misspellings? (Fuzzy search, suggestions, autocorrect)
- Search autocomplete: Product titles, subjects, sellers, categories?
- Search history: Save recent searches, show popular searches?

**2. Advanced Search Operators:**
- Should we support advanced search syntax? ("grade 7 math" -science, exact match "quotes", OR operator)
- Or keep it simple with filters only? (Teachers may not be tech-savvy)
- Filter combinations: AND/OR logic? (Match ALL filters vs match ANY filters)
- Saved searches: Let users save search queries with filters for quick access?

**3. Search Results Page:**
- Layout: Grid view vs List view vs Both with toggle?
- Results per page: 20, 50, 100? User selectable?
- Sort options: Relevance, Newest, Bestselling, Price (low-high, high-low), Highest Rated, Most Viewed?
- No results behavior: Show suggestions, popular products, related categories?
- "Did you mean?" suggestions for misspellings

**4. Filter System Enhancement:**
- From Feature 03 we have: Product Type, Grade, Subject (dynamic), Quarter, Weeks, Price, Rating, File Type
- Should we add more filters?
  - Seller verification status (Verified only)
  - Date added (Last 7 days, Last 30 days)
  - Price range presets (Under ₱50, ₱50-₱100, ₱100-₱300, Over ₱300)
  - Language (English, Filipino, Bilingual)
  - File size (Small under 10MB, Medium 10-50MB, Large over 50MB)
- Filter behavior: Show number of results per filter option? ("Math (124)")?
- Active filters display: Chips or list? "Clear all filters" button?

**5. Category Pages & Browse:**
- Should we create dedicated category pages? (/products/lesson-plans, /products/exams, /products/grade-7)
- What should category pages show? (Hero section, Featured products, All products in category, Filter sidebar)
- Subcategory navigation: Breadcrumbs, sidebar, tabs?
- Category-specific filters? (Only show Quarter filter for Lesson Plans, Only show Theme filter for RPMS)

**6. Product Recommendations:**
- "Related Products" section on product page: Based on what? (Same grade, same subject, same seller, bought together, viewed together)
- "You might also like" on homepage: Personalized recommendations? (Based on browsing history, purchase history, popular in your grade level)
- "Similar Products" on search results: If no exact matches, show close alternatives
- Collaborative filtering: "Teachers who bought this also bought..." (requires purchase data)

**7. Search Analytics for Sellers:**
- Should sellers see what keywords buyers use to find their products? (Search term report)
- Search volume: How many people searched for "grade 7 math" this month?
- Click-through rate: How many times did product appear in search vs clicked?
- Ranking position: Where does my product rank for keyword "grade 7 math"?
- Search performance tips: "Your product appears on page 3 for 'grade 7 math'. Add 'Quarter 1' to title to improve ranking."

**8. SEO & Discoverability:**
- Product URL structure: /products/grade-7-math-dll-q1 or /products/[id]?
- Meta tags: Dynamic meta title, description, Open Graph for social sharing
- Schema.org markup: Product, Seller, AggregateRating structured data?
- Sitemap: Auto-generated XML sitemap for products and sellers
- Canonical URLs: Prevent duplicate content issues

**9. Search Performance & Caching:**
- Search results caching: How long? (1 minute, 5 minutes, no cache?)
- Popular searches cache: Pre-compute results for top 100 searches?
- Database indexing: Which fields need indexes? (title, description, grade, subject, tags)
- Search query optimization: Avoid slow LIKE queries, use full-text search
- Handling 10,000+ products: Performance considerations

**10. Mobile Search Experience:**
- Search bar behavior: Sticky at top, always visible?
- Voice search: Add microphone icon for voice input? (Useful for teachers on-the-go)
- Camera search: Scan textbook or curriculum guide to find related products? (Too complex for MVP?)
- Search suggestions on mobile: Show 5-10 suggestions, scrollable list
- Filter drawer: Slide-out from left (like e-commerce apps)
