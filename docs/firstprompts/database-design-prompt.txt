## IMPORTANT REMINDERS

- **Cursor + Supabase MCP:** You're using Cursor AI with Supabase MCP server. The database schema should be clean, well-documented, and ready for AI-assisted development.
- **TypeScript Generation:** Schema should be compatible with `supabase gen types typescript` command.
- **Migration-First:** Design migrations that can run incrementally (not one giant script).
- **Production-Ready:** This is the database that will run in production. Get it right now.
- **No Shortcuts:** Don't skip indexes, constraints, or RLS policies "for now." Do it right from day one.
- **Filipino Context:** Remember this is for Filipino teachers (Tagalog text search, PRC license validation, etc.).
- **Mobile-First:** Database should support PWA mobile usage (efficient queries, minimal data transfer).
- **Performance Matters:** Slow database = slow platform. Index correctly from the start.
- **Security First:** RLS policies prevent data leaks. Test them before deploying.

## NEXT STEPS AFTER DATABASE DESIGN

Once database schema is complete:

1. **Generate TypeScript Types:**
   ```bash
   supabase gen types typescript --project-id YOUR_PROJECT_ID --schema public > types/supabase.ts
   ```

2. **Create Supabase Project:**
   - Go to supabase.com
   - Create new project
   - Get project URL and anon key

3. **Run Migrations:**
   ```bash
   supabase link --project-ref YOUR_PROJECT_ID
   supabase db push
   ```

4. **Set Up Storage:**
   - Create buckets: `products`, `avatars`, `message-images`
   - Set storage policies

5. **Configure Auth:**
   - Enable email/password auth
   - Enable Google OAuth
   - Enable Facebook OAuth

6. **Start Development with Cursor:**
   - Connect Cursor to Supabase
   - Use MCP server for database operations
   - Build API routes
   - Build frontend components
